# Foundations

Start here, then move through the numbered topic folders in order. Each folder contains programs for a related concept.

| Folder | Topic | Programs/examples |
|---|---|---|
| [00_overview](00_overview/data_ingestion.md) | Vocabulary | Data ingestion |
| [01_python_basics](01_python_basics/dictionary.py) | Python core | Dictionaries, functions, filtering, aggregation |
| [02_files_csv_json](02_files_csv_json/) | Data formats | Text files, CSV, JSON |
| [03_validation_exceptions](03_validation_exceptions/) | Data quality | Validators, exceptions, rejected inputs |
| [04_logging](04_logging/logger.py) | Observability | Logger, handlers, rotating file output |
| [05_api_etl](05_api_etl/) | API/ETL exercises | Requests, pagination, retry, transformations, CSV/JSON |
| [06_sql_postgresql](06_sql_postgresql/) | SQL notes | SQL progress and JOIN recall |
| [07_python_postgresql](07_python_postgresql/) | Database driver | Connect, fetch, parameterized SQL, insert, transactions, retries |

For the file-level descriptions and run requirements, see the [program catalogue](../docs/FILE_CATALOG.md). For what to study next, see the [roadmap](../docs/ROADMAP.md).

**Run commands from the repository root** unless stated otherwise. Old file exercises may require local sample files under `Data/`.
